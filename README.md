# 同人译站

一款 HarmonyOS NEXT 上的同人小说**抓取 · 翻译 · 阅读**助手。支持 AI 对话式找文、FicHub 一键转 EPUB、本地导入，并内置基于大模型的逐章翻译流水线（含术语表）。

> **使用须知**：
> 1. 仅供个人学习与技术研究使用，不得用于商业用途；
> 2. 抓取与翻译的内容版权归原作者及原站点所有，导出的文件请勿分发、转载；
> 3. 请遵守各目标网站的服务条款，本应用不提供绕过登录、付费或版权保护的能力，也无法保证对所有站点有效。

## 功能特性

### 🔍 AI 找文（对话式 Agent）
- 像聊天一样描述需求：「HP 时间穿越的长篇同人文」，或直接丢一个链接
- 模型自主调用 10 个工具完成整个流程：搜索（`web_search`）、读网页（`fetch_page`）、取书三条路（`fichub_get` / `html_to_book` / `download_file`）、诊断与自愈（`debug_fetch` / `http_probe` / `manage_site_rules` / `read_recent_logs` / `list_links`）
- **多种抓取手段自动降级**：静态页直抓 → JS 动态页用内置无头浏览器渲染 → 页面空壳时探接口取数据，每级失败都有下一级兜底
- **站点规则 + 自愈**：内置常见站点（LOFTER、晋江、B 站专栏、百度贴吧等）的正文抽取规则；遇到没见过的站点，模型可以用 `debug_fetch` 做体检、自己写规则并验证，规则落盘后永久生效
- **等价地址归一**：贴吧 `/p/` 链接、B 站专栏等会被自动改写成免登录、可分页的等价地址，用户分享什么链接都能直接抓
- 会话自动保存：多会话列表可切换、删除、接着上次聊；思考过程与工具调用全程流式上屏，可随时中断
- 命中的书先进「待入库区」，确认后才进书架；已下载过的作品自动去重

#### 能力边界

| ✅ 擅长 | ❌ 不擅长 |
|---|---|
| FicHub 覆盖的站（AO3、FFN 等英文同人站） | 登录墙内的内容（VIP 章、私密帖、仅关注可见） |
| LOFTER、微博头条文章 | 强反爬站点（知乎等，多数时候过不去） |
| 晋江**免费**章节、贴吧连载帖（整帖只看楼主） | 付费/VIP 内容（明确不支持） |
| B 站专栏、博客、论坛长帖 | 以图片/长图为主体的正文 |
| 公开、免登录、以文本为主的内容 | 站点改版后规则失效的窗口期 |

其它已知限制：单次任务有工具调用步数上限，超大抓取任务可能中途收手；连载未完结的书只能抓到已发布部分；部分站点匿名访问无法翻页，只能拿到前几页。

### 📥 本地导入
- 支持 EPUB / TXT / HTML 三种格式，文件解析后自动分章入库
- 默认跳过书架里已有的书（内容指纹 + 标题作者双层去重），需要时可用开关允许重复导入
- 在浏览器里看到想收藏的作品页时，通过系统「分享」菜单把链接分享给本应用，无论冷启动还是热启动都会带着链接直达 AI 找文对话，省去复制粘贴

### 📚 书架
- 分组管理：自定义分组、长按删除分组（书自动退回「未分组」）
- 手动排序：排序模式下 ↑↓ 调整顺序，分组内重排不影响其它分组
- 从搜索页、导入页一键入库，重复导入自动识别（内容指纹 + 标题作者双层去重）

### 📖 阅读与翻译
- EPUB / TXT / HTML 解析入库，分章阅读
- 基于 OpenAI 兼容接口的逐章翻译流水线（支持 DeepSeek 等任何兼容服务商）
- 术语表：自定义译名对照，翻译时统一人名/地名/专有名词
- 翻译任务可中断续跑，进度持久化

### 📤 排版导出
- 三种格式：**EPUB**（默认）/ HTML / TXT，手机上直接保存到「下载」「文档」等公共目录
- 双语对照：原文作为灰色小字参考段、译文为正文；也可只导纯译文
- 未翻译的段落自动用原文填充，导出内容没有空洞
- 斜体/加粗/下划线/删除线样式保真；EPUB 含完整目录（兼容 EPUB 2 旧阅读器），可直接导入任意阅读 App

## 使用示例

### ① 一句话找文 → 自动下载 → 进书架

在「AI 找文」页直接描述需求：

> **我**：帮我找 HP 里时间穿越题材的长篇同人，完结的
>
> **模型**：（思考过程流式上屏）→ 调用 `web_search` 搜索 → 挑出 2 个最符合的候选 →
> 并行调用 `fichub_get` 抓取转换 → 每本下载完成后在对话里给出卡片
>
> **模型**：找到了 2 部完结长篇：①《…》 42 万词 · 156 章 ②《…》 28 万词 · 98 章，都已下载。
>
> **我**：点命中卡片上的「加入书架」（或点「全部加入书架」）→ 书立即出现在书架

追问「再找几本类似的」会继续；已经下过的书再点不会重复请求 FicHub。

### ② 浏览器里看到想收藏的文

在浏览器打开作品页 → 点「分享」→ 选「同人译站」→ App 自动打开 AI 找文对话并带上链接，说一句「下载这本」即可。

### ③ 翻译与导出

1. 书架点开一本书 → 点右上角「目录」→「连翻 10 章」或「翻完剩余」（可随时中断，下次继续）
2. 阅读时切换 **原文 / 双语 / 译文** 三种模式
3. 目录页点「导出…」→ 选 范围（全书/当前章）× 内容（纯译文/双语对照）× 格式（EPUB/HTML/TXT）→ 系统保存对话框选位置
4. 导出的 EPUB 可直接在华为阅读、静读天下等任何阅读 App 打开，目录可跳转；也可以在书架卡片「⋯」菜单里选「导出全书…」，不进阅读器直接导

## 构建运行

**环境要求**：HarmonyOS NEXT 鸿蒙手机（系统版本 6.1.0 / API 23 及以上）；不支持 Android 设备与旧版 HarmonyOS（2.0/3.0 等可装 APK 的版本）。

1. 安装 [DevEco Studio](https://developer.huawei.com/consumer/cn/deveco-studio/)（需支持 API 6.1.0(23)）
2. 克隆本仓库后用 DevEco Studio 打开
3. `File > Project Structure > Signing Configs` 勾选 **Automatically generate signature** 自动生成调试签名
4. 连接真机或启动模拟器，Run 即可

命令行构建：

```bash
hvigorw.js assembleHap --mode module -p product=default -p buildMode=debug --no-daemon
```

## 配置说明

在 App 内 **设置** 页填写：

| 配置项 | 说明 |
|---|---|
| LLM 服务商 | 任意 OpenAI 兼容接口（Base URL + API Key + 模型名），默认预设 DeepSeek |
| Tavily API Key | AI 找文使用，[tavily.com](https://tavily.com) 免费申请 |

API Key 仅保存在设备本地偏好中，不上传任何服务器。

## 工程结构

```
entry/src/main/ets/
├── pages/          # 页面：书架、AI 找文、导入、阅读、术语表、设置
├── fetch/          # AI 找文 Agent：工具集、抓取管线（直抓/无头渲染/等价地址归一）、
│                   #   站点规则引擎、反爬识别、FicHub 客户端、待入库区与会话存储
├── parser/         # EPUB/TXT/HTML 解析入库
├── translator/     # 翻译流水线（分章任务、术语注入）
├── provider/       # LLM 调用封装（OpenAI 兼容协议 + SSE 流式）
├── export/         # 排版导出（TXT/HTML/EPUB；含手写 stored-zip 打包器）
├── data/           # 关系型数据库 DAO（作品/章节/段落/术语/进度）
├── model/          # 数据模型
└── common/         # 日志等通用工具
```
